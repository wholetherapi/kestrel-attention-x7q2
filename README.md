# Kestrel-Attention

Implementation of **"Kestrel-Attention: Block-Sparse Attention Kernels for
Long-Context Transformers"** (arXiv:2505.01233, ICLR 2026).

This repository implements the Kestrel-Attention model family. It does **not**
implement the Kestrel sparse tensor engine paper (arXiv:2503.11488) and is not
affiliated with that project.

Requires Node.js 18 or newer for the reference kernels.
